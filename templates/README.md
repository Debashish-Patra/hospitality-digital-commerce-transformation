# Templates

Downloadable, editable versions of the reusable templates in [Leadership Lessons](../docs/06-leadership-lessons.md#reusable-templates). Each file is blank apart from one clearly marked illustrative example. Do not enter confidential client information in a public copy.

| Template | File | Format |
|---|---|---|
| A. Product opportunity brief | [01-product-opportunity-brief.docx](01-product-opportunity-brief.docx) | Word |
| B. Cross-functional decision log | [02-cross-functional-decision-log.xlsx](02-cross-functional-decision-log.xlsx) | Excel (status drop-down, summary counts) |
| C. Executive status summary | [03-executive-status-summary.docx](03-executive-status-summary.docx) | Word |
| D. Launch readiness checklist | [04-launch-readiness-checklist.xlsx](04-launch-readiness-checklist.xlsx) | Excel (status drop-down, readiness % and go / no-go signal) |

To download a file, open it on GitHub and choose **Download raw file**, or clone the repository.
